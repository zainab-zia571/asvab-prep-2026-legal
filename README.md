# ASVAB Prep 2026 — legal site

The privacy policy, terms and contact page for the **ASVAB Prep 2026** Android
app, published for Google Play's policy-link requirement.

Plain HTML and one stylesheet: no build step, no scripts, no fonts or images
loaded from anywhere else. The same text is bundled inside the app so it can be
read with no connection.

| Page | Purpose |
| --- | --- |
| `index.html` | Landing page and summary |
| `privacy.html` | Privacy Policy |
| `terms.html` | Terms & Conditions |
| `contact.html` | Contact details |

Served with GitHub Pages from `main`, at the repository root.
